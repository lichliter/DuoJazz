## Practice organization

The intended structure is **lick → application → practice tune**:

- A lick is the vocabulary being learned and mastered across keys.
- An application describes the harmonic situation where that lick works.
- A practice tune provides a musical context for that application. A tune can support several applications of the same lick.

For Cry Me a River, **minor home** and **altered dominant** are applications. Both can be practiced over **Autumn Leaves**. They are not separate tunes. Apply this distinction when organizing practice for all thirty licks.

The workbook's printed pages 1–2 introduce Cry Me a River, illustrate its use over different chords, and give examples within common progressions. Use the engraved examples to establish each lick's applications. Distinguish workbook examples from app-selected practice tunes; do not attribute a tune choice to the workbook without evidence.
